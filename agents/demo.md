# The demo site

Part of the notes for coding agents; [AGENTS.md](../AGENTS.md) has the overview and the index.

- **The demo** (`demo/`; published at `digress.neejweej.workers.dev` via Cloudflare Workers Static Assets with `demo/wrangler.jsonc` and `_headers`, while `neejweej.github.io/digress` redirects there via `demo/redirect.html`; files are stored as bytes, since Safari's private browsing can't keep a Blob in IndexedDB): `demo/build.mjs` copies `web/` and adds only two `<script>` tags at the top of `<head>`: `demo/replies.js` and `demo/demo.js`, an in-browser stand-in for the server that answers `api/*` (IndexedDB for conversations, cards, layouts and files; relative to the page). So the demo is always the current page, and anything that changes the server contract must change `demo/demo.js` too. Its corner note (`#demoNote`) can be dragged, minimized on phones, or hidden completely (`digress:demo-note-hidden` in `localStorage`) and brought back from the sidebar bar (`#demoSide`, which also gives quick access to API key Connections and Start over). By default replies come from `DemoReplies.reply(body)` (written in advance for the sample reading, `PREPARED`, keyed by the question; its `[p. N]` must match `demo/sample.pdf`; otherwise quoting the document's closest passages and saying it's the demo). The seed's conversations are in the **Demo conversations** folder, and its PDF's id is derived from `demo/sample/bayes.html` (`make_sample.py`), so it stays the same from one seed to the next; a newer seed replaces the old sample's conversations and cards but never deletes files (`seed()` runs `sweepFiles`, which removes only what nothing uses): a conversation kept from an old sample (the copy a tab that had it open saves, `deletedElsewhere`) keeps its PDF. The tab's title always starts with `Demo · `, a Gemini key connected or not (`demoTitle`). Takeaways in the seed are a real model's (`demo/make_sample.py --record` sends the page's own takeaway requests to a Digress server and keeps them in `demo/sample/takeaways.json`, handed to the page only while it builds the seed: `window.__seedTakeaways`); one a visitor asks for is `takeaway()`'s stand-in, 2–3 one-sentence bullets picked from what the branch found, labeled as such. Visitors can also connect their own Google Gemini API key in Connections: the browser calls `generativelanguage.googleapis.com` directly (with document tools, `suggest_card`, and optional Google Search) through **the server's own code, not a copy**: `demo/build.mjs` copies `server/gemini.mjs`, `doctools.mjs` and `content.mjs` into `demo/server/`, and `demo.js` imports them (`shared()`) and does only what `handleChat` does around them (normalize the messages, pick the default model with `gemini.defaultModel`, open the tools' session, give `gemini.chat` an `io` that writes into the response's stream, answer `/api/chat/tool` with `deliverResult`). So those three files stay free of Node APIs (`env` from `globalThis.process`, `atob`, Web Crypto; the demo passes its unpatched `fetch` with `gemini.configure`); `tests/test_demo_shared.py` fails if one isn't, or if `demo.js` grows its own Gemini request, stream, tool budget or message check again. The key stays in a private closure in memory by default or optionally password-encrypted in IndexedDB (`byok/gemini`, `PBKDF2-SHA256` 600k iterations + `AES-GCM-256`). It has its own service worker, `demo/sw.js`, in place of the app's: it keeps nothing offline and only revalidates every request (`cache: 'no-cache'`), since GitHub Pages sends `max-age=600` and a visit after a deploy otherwise opened the old page for ten minutes (`tests/test_sw_fresh.py`, Chromium only: Playwright's WebKit doesn't send a navigation with a fresh cached copy through the service worker at all, so whether Safari gets the new page at once is unchecked). The sample conversation (`demo/seed.json`) is made by `demo/make_sample.py`, which prints `demo/sample/bayes.html` to PDF and clicks through the built demo; rerun it when the reading or the prepared replies change. "Ask about Digress" reads `demo/guide.json`, built from `guideDocs()` (`server/guide.mjs`). `tests/test_demo.py` builds the site and drives it.
